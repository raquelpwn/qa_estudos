## 🧪 Exercícios

### Análise e identificação de bugs

Prática de análise de uma página web, identificando problemas relacionados a:

* Formatação de texto
* Espaçamento
* Links quebrados
* Erros 404
* Imagens que não carregam

Os problemas encontrados foram documentados utilizando informações como:

* O que foi observado
* É um bug?
* Passos para reproduzir
* Resultado esperado
* Resultado atual
